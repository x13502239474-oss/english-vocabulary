# 词根联想英语词汇小程序（网页离线版）

## 功能

### 单词学习

- 词库 **1830 条**（英文、音标、释义、记忆提示、例句）。
- 词库按**字母顺序 A→Z** 排列（`a/an` → `zoo`），相同首字母的单词自然聚在一起。
- **按顺序学习**：默认顺序推进，自动记住上次学到第几个，下次打开接着来；  
  末尾自动回卷到开头。也可切「随机」模式随机抽词。
- **跳到单词**：输入英文直接从那个词开始学。支持自动补全、大小写不敏感、只打开头几个字母也能匹配，还可以按中文释义找（如输入「苹果」）；回车或点「跳转」均可。
- **最近学过**：自动记录最近浏览过的 **10 个单词**（翻页、跳转都算），点一下就能跳回去，可一键清空。记录保存在浏览器里，下次打开还在。
- **学习范围**：全部单词 / 只看未掌握 / 只看待复习。
- 标记已掌握、加入待复习（点「还不熟」）。

### 短句学习

- 短句库 **1739 条**（英文句子 + 中文翻译 + 关联单词），从电子书的【例】句提取。
- 短句按**关联单词的字母顺序**排列，顺序与单词学习一一对应（学到哪个词，就配哪个词的例句）。
- 同样支持按顺序 / 随机、范围筛选、标记掌握与待复习。
- 🔊 整句朗读，🐢 慢速朗读。

### 小测验（看词选义）

- 显示单词，从四个中文释义里选正确的。

### 听力测试

- **听单词 · 选拼写**：只放发音，从四个形近/同首字母的单词里选出听到的那个。
- **听句子 · 选意思**：放整句，选正确的中文翻译。
- 支持每题自动播放、重听、慢速播放；答完显示正确答案与音标。

### 口语跟读

- 用浏览器语音识别跟读单词或短句，给出**相似度评分**和**逐词比对**  
  （绿色=读对，红色=漏读或读错），并累计平均分。
- 有「听示范」「慢速示范」，可先听后读。
- **环境要求**：需要 Chrome / Edge，需要**联网**（识别在云端完成），  
  需要授权麦克风，且必须通过 **<http://localhost> 或 https** 打开  
  （直接双击 index.html 用 file:// 打开时浏览器会禁用麦克风）。  
  环境不满足时页面会给出明确提示，且不会报错崩溃。

### 默写练习

- **默写单词**：给中文释义 + 音标 + 首字母提示（`p _ _ _ _ _ _`），写出英文单词。
- **默写短句**：给中文翻译，写出整句英文。
- 判定规则：**只看拼写与用词**——大小写、多余空格、句末标点、中英文撇号形态都不算错。
- 单词写错一两个字母会提示「差一点」并给出相似度；短句按**逐词比对**标出漏写/写错的词
  （绿=写对，红波浪线=漏写或拼错），并显示相似度百分比。
- 范围可选：全部 / 只看未掌握 / 只看待复习 / **只看默写错过的**（默写错的自动进错题集，写对后自动移出）。
- 答题操作：输入后按 **Enter** 提交；**答完再按 Enter** 直接进入下一题。
  另有「给点提示」「看答案」「跳过 →」；输入法是候选词状态时回车不会误提交。
- 可勾选：显示首字母提示 / 答错加入待复习 / 答对后朗读。正确率、连对、最佳连对实时显示。
- 题型、范围、模式、位置与勾选项都会记住。

### 英语测试卷（初中级别，自动出卷）

- 标签栏最后一个「测试卷」。点「生成新卷」从词库与短句库自动组成一份 **满分 100 分** 的试卷，
  可选「全部单元」或指定某个 Word List 出卷；同一份卷子刷新后还在（记录了出卷种子）。
- **三档难度**（切换难度会立刻按新难度重出一份卷）：
  - **普通（基础巩固，建议 40 分钟）**：只考靠前 1/3 单元；干扰项随机、差别大；单选附中文释义提示；方框不多给词；翻译 3 英译中 + 2 中译英；短文 5 句（判断正误 + 词义题）；写作 5 词、40 词以上。
  - **进阶（能力提升，建议 45 分钟）**：全部单元；干扰项同首字母、长度接近；无提示；方框多给 2 个干扰词；翻译 2 + 3；短文 6 句并新增「找出短文里没有的那一句」扫描题；写作 5 词、60 词以上。
  - **精通（冲刺拔高，建议 50 分钟）**：优先长句难句；干扰项同词性同首字母；方框多给 4 个干扰词；翻译 1 + 4（以中译英为主）；短文 7 句、判断 + 扫描 + 词义三类题都有；听力语速加快；写作 6 词、80 词以上。
- **一、听力理解（20 分）**：A 段听单词选单词、B 段听句子选中文意思，点 🔉 播放、可重复听。
- **二、语言运用（30 分）**：单项选择 10 题（词库短句挖空，4 选 1）+ 选词填空 10 题（方框给词，每词限用一次）。
- **三、翻译（15 分）**：英译中 + 中译英（比例随难度变化），提交后按与参考答案的相似度自动判分（仅供参考）。
- **四、阅读理解（20 分）**：由同一单元的句子组成短文（用于练习句子理解，不是原文课文），
  判断正误 + 扫描题 / 词义题（随难度变化），共 5 题。
- **五、书面表达（15 分）**：给若干个单词写一段短文（词数要求随难度变化）；提交后统计词数与指定单词使用情况，
  给出机器参考分，并附参考范文（由这几个词的例句组合，仅供句式参考）。
- 点「提交评分」自动判分：每题标对错、给正确答案与原句解析，顶部显示总分与分项得分，
  并记录最近 5 份的成绩；最高分按难度分开统计。
- 点「打印试卷」可以打印成纸质卷（自动隐藏页面其它部分，只打印试卷；听力部分需在电脑上做）。

### 发音

- 口音：自动 / 美音 en-US / 英音 en-GB。
- **声音：女声（默认）/ 男声 / 不限。**
- 语速：慢速 / 正常 / 较快；另可勾选「切换时自动朗读」。
- 快捷键 `S` 朗读当前内容。
- 全部使用浏览器内置语音合成（Web Speech API），**不联网、不需要 API Key**。
- 页面上会实时显示「当前语音：xxx（en-US · 女声）」，方便核对。

### 其他

- 词库检索：可在**单词/短句**之间切换，按 Word List 筛选、搜索、分页加载。
- 待复习页同时列出待复习单词与待复习短句。
- **已掌握页**：顶部「已掌握单词」「已掌握短句」两张统计卡可以直接点进去
  （标签栏里也有「已掌握」标签），具体列出你掌握了哪些单词/短句——
  按 A→Z 排列并带首字母分组标题，每条都有 🔊 朗读、「重新学习」和「取消掌握」
  （点了就从已掌握移回待学习，统计同步变化）。顶部有筛选框，掌握得多了也能快速找到某个词；
  超过 200 条时分批显示，点「显示更多」继续看。
- 测试卷：一键生成初中级别的综合试卷（听力 / 语言运用 / 翻译 / 阅读理解 / 写作），
  可自动判分、可打印，详见上文「英语测试卷」。
- 学习记录与各项偏好（口音、声音、语速、模式、进度）都保存在浏览器 localStorage。
  **例外**：在受限的沙箱环境（如某些应用的内置预览面板）里浏览器会禁用 localStorage，
  页面会自动退回"内存模式"照常运行，只是**关掉后进度不保留**；想保留进度就用双击/浏览器打开。

## 文件说明

| 文件               | 说明                        |
| ---------------- | ------------------------- |
| `index.html`     | 整个应用（HTML + CSS + JS 单文件），**需要本地服务器打开** |
| `words.json`     | 单词库，1830 条                |
| `sentences.json` | 短句库，1739 条                |
| `离线单文件版.html`    | 词库已内嵌，**双击即可用，不需要服务器**  |
| `index.html.bak` | 加发音功能之前的原始备份              |
| `启动.bat`         | 双击即可启动本地服务器（不用敲命令）        |

> `离线单文件版.html` 由 `index.html` + 两个 json 自动生成；改完 `index.html` 后重新生成一次即可。

> 词库与短句内容提取自你提供的电子书，仅供个人学习使用。

## 打开方式

### 只想背单词：双击 `离线单文件版.html`

词库和短句都已内嵌在文件里，双击直接就能用，**不需要服务器、不需要联网、不需要 Python**。
发音、顺序学习、短句学习、听力测试、**默写练习**全都可用；只有**口语跟读用不了**（浏览器要求 localhost/https 才给麦克风）。

> 为什么不直接双击 `index.html`？浏览器的安全策略禁止 `file://` 页面读取本地 json 文件，
> 所以直接双击 `index.html` 会一直显示「词库加载失败」。这是浏览器限制，不是文件坏了。

### 要用口语跟读：双击 `启动.bat`

会弹出一个黑窗口，在 8000 端口起服务，并自动打开浏览器。

- **学习期间不要关掉那个黑窗口**，否则网页会打不开。
- 想停止：按 `Ctrl+C`，或直接关掉窗口。
- 提示找不到 Python 时，先安装 <https://www.python.org/downloads/>（安装时勾选 “Add Python to PATH”）。

### 或者自己敲命令

```bash
cd 本文件夹
python -m http.server 8000
```

然后浏览器访问 <http://localhost:8000>，推荐 Chrome 或 Edge。

> ⚠️ **不要直接双击 index.html**。那样浏览器会限制读取 JSON，而且口语测试拿不到麦克风权限。

## 发音相关提示

- 默认是**女声美音**。若没有声音：先确认系统音量，再到 Windows  
  「设置 → 时间和语言 → 语音」检查英文语音包。
- 本机自带 Microsoft David / Mark（男声）、**Zira（女声）**，Edge 还提供更自然的在线语音。  
  Web Speech API 不提供性别字段，程序是**按语音名推断**性别的；若某个语音无法判断性别，  
  它会作为备选保留（不会被误排掉）。
- 切换口音/声音后，页面上的「当前语音」会立刻更新，可以直接看到实际选中了哪个语音。
- 首次发声需要先点一下页面（浏览器自动播放限制），所以打开时不会自动读第一个词。

## 数据是怎么来的

`sentences.json` 由 `build_sentences.py` 从电子书提取：电子书里例句的英文和中文是**连在一起**的  
（如 `He is a doctor.他是医生。`），脚本按**首个汉字或中文标点**切开，并修正了若干 OCR 错误  
（`ln`→`In`、`cuItura`→`cultura`、全角标点、数字与字母粘连等）。  
脚本可重复运行，每次都会打印质量校验报告。
