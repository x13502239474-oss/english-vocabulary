# THE NORTHERN LEXICON · 北境词林

高中英语自学网站。一套写实的北境清冷白日世界 UI 系统，覆盖全部 13 个学习模块。
词库内嵌于 `index.html`，离线可用；写实素材与欧洲字体为本地文件/内嵌字体，不依赖任何付费 API 或云服务。

## 设计概念

不是「游戏皮肤」，而是把那个世界的材质与制度做成可复用的界面构件：

| 世界意象 | 界面构件 |
|---|---|
| 北境清冷白日 / 雪峰松林 / 古老石堡 | 写实首屏大图（5 张北境场景轮换）、城墙垛口顶栏与图片下缘、石砌分隔线 |
| 重甲骑士 | 14 枚线性纹章盾徽（每章一枚）、斜切锻铁铭牌按钮与铆钉、皮革绑带 |
| 斑驳铁剑 | 铁剑进度条：掌握度把暗铁剑身锻成亮银；页边同步小剑 |
| 手抄本 / 火漆 | 泥金首字母、哥特拱窗式页眉、火漆封印反馈、羊皮纸纤维底纹、拉丁题铭 |

- **字体**：`Cinzel`（罗马碑铭，章节/徽记）、`Cormorant Garamond`（古印刷衬线，词头/例句）、
  `UnifrakturMaguntia`（哥特体，泥金首字母）。均为 SIL OFL 开源字体，latin 子集已 base64 内嵌，离线生效。
- **写实素材**：`assets/scene-01..05.jpg`（同一座城堡的晨光 / 落日 / 晨雾 / 冬日 / 内庭五幅场景）、
  `assets/parchment.jpg`（羊皮纸纤维底纹）、`assets/relics.jpg`（斑驳铁剑 / 盾徽 / 火漆卷轴），
  另有 `hero.jpg` 作首帧兜底。由生成图裁去水印、压缩而来，本地存放，共约 1.6 MB。
- **进度可视化**：40 处遗迹按每个 Word List 的真实掌握率着墨；铁剑按词库着墨率锻亮；
  页边「技艺刻度」标出当前走到第几章。全部读本机真实记录，不虚构数据。
- **动效**：书页翻入、剑身锻亮、火漆盖印、纹章点亮、目次抽屉；全部 ≤0.7s，尊重 `prefers-reduced-motion`。

## 卷首场景轮换

同一座城堡在不同时间、季节与视角里自动换画，而不是永远一张图。首屏右下角的石匾显示当前场景名并带控件：

| 周期 | 行为 |
|---|---|
| 每日（默认） | 按日期在五幅场景间轮换，每天一幅 |
| 每周 / 每月 | 按 ISO 周 / 月份轮换 |
| 随时段 | 清晨薄雾、日间晨光、傍晚落日、夜间内庭 |
| 每次打开 | 每个浏览器会话换一幅 |
| 固定 | 锁定当前这一幅 |

- 点「↻ 换一幅」手动切下一幅，并自动切到「固定」；想恢复自动，在下拉里重选周期即可。
- 页面一直开着也会跨天 / 跨时段自动切换（每分钟检查一次），不需要刷新；切换有 0.55s 淡入，其余场景空闲时预载。
- 设置存本机 `hs-vale-cycle` / `hs-vale-scene`，不影响学习进度。

## 页面与功能

- 扉页（卷首大图 / 主线委托 / 铁剑 / 四十遗迹 / 今日三枚符文 / 开卷入口 / 版本记）
- 单词学习 / 短句学习 / 语法学习 / **音标学习**（48 国际音标：总表 + 听音辨音 + 认读音标）
- 词库检索 / 待复习 / 已掌握
- 小测验 / 听力测试 / 口语跟读 / 默写练习 / 测试卷 / 语法测试
- 词条页「词条铭牌」：字屉、分级、词频、20 天计划、序位、是否有真题例句
- 进度导出 / 合并（在词库检索中），localStorage 键 `hs-vocab-*` 与旧版完全兼容

## 数据来源

绿宝书系列版（主词库）+ 20 天背完高考核心词汇（高频标记 / 真题例句 / 20 天计划）+ 海豚版（校补）。

## 构建链

```
python design/fetch_fonts.py       # 首次：下载开源欧洲字体 -> design/fonts.css（base64）
python design/prepare_assets.py    # 首次：裁水印/压缩五幅场景与底纹 -> assets/scene-01..05.jpg 等
python design/apply.py             # 把设计系统注入 _template.html
python build_app.py                # 注入高中词库 -> 单文件 index.html
```

字体与图片已处理完毕并提交在项目中，日常改动只需后两步。

- `build_data.py`：从 EPUB 生成 `data/words.json`、`data/sents.json`、`data/meta.json`。
- `design/theme.css`：全部视觉样式（追加在原组件样式之后）。
- `design/theme.js`：铁剑 / 遗迹 / 符文 / 题铭 / 铭牌 / 火漆 / 抽屉。
- `design/apply.py`：重组书页框架、生成纹章目次与扉页，注入字体、CSS、JS、favicon。
- `design/_template.before.html`：未改造的原始模板备份，`apply.py` 每次从它读取，可反复运行。
- `design/preview/final-*.png`：桌面 / 手机端实际渲染截图。

## 修改注意

- **改界面**：改 `design/theme.css`、`design/theme.js`、`design/apply.py`，依次重跑
  `python design/apply.py` 和 `python build_app.py`。
- **只改词库**：改 `data/*.json` 后重跑 `python build_app.py`。
- 不要直接改 `index.html`：它由构建脚本生成，重跑会被覆盖。
- 原模板的 13 个学习模块、`id`、事件绑定、快捷键与 localStorage 键全部保留；
  设计层只重组外层框架，不改动学习逻辑。
